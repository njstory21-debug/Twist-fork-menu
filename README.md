# TWIST & FORK PASTA — เว็บเมนูพร้อมใช้กับ GitHub Pages

เว็บแบบไฟล์ธรรมดา (HTML / CSS / JavaScript) ไม่มีค่าใช้บริการ Lovable ไม่ต้องติดตั้งแพ็กเกจ ไม่ต้องสั่ง build และไม่ต้องใส่รหัสลับ

## ใช้งานในเครื่องก่อน

เปิด `index.html` ด้วย Chrome, Edge หรือ Safari รูปเมนูและปุ่มเลือกอาหารจะทำงานได้ทันที การแชร์ลิงก์ให้ผู้อื่นเปิดได้ต้องเผยแพร่เว็บก่อน ส่วนการคัดลอกข้อความอัตโนมัติอาจถูกเบราว์เซอร์จำกัดเมื่อเปิดจากไฟล์ — มีช่องข้อความให้เลือกคัดลอกเองได้

## เผยแพร่บน GitHub Pages ครั้งแรก

1. แตกไฟล์ ZIP ที่ได้รับ จะเห็นโฟลเดอร์ `twist-fork-github-pages` และไฟล์ `index.html`, `style.css`, `app.js`, `menu.js`, `favicon.svg`, `.nojekyll`, `README.md` กับโฟลเดอร์ `assets`
2. เข้าบัญชี GitHub แล้วสร้าง repository ใหม่ เช่น `twist-fork-menu` เลือก **Public** สำหรับวิธีใช้ GitHub Pages ฟรีแบบง่าย ๆ นี้ ไม่ต้องใส่รหัสผ่านหรือข้อมูลลูกค้าใน repository
3. เข้า repository กด **Add file → Upload files** (ถ้า repository ยังว่าง ให้เลือก **uploading an existing file**)
4. ลาก **ไฟล์และโฟลเดอร์ทั้งหมดที่อยู่ข้างใน** `twist-fork-github-pages` ขึ้นไป รวมโฟลเดอร์ `assets` ด้วย ต้องให้ `index.html` อยู่ชั้นบนสุดของ repository ไม่ใช่อยู่ซ้อนในโฟลเดอร์อีกชั้น
5. กด **Commit changes** เพื่อบันทึก หากตัวเลือกอัปโหลดมองไม่เห็น `.nojekyll` ก็ยังเผยแพร่เว็บชุดนี้ได้ เพราะไม่มีโฟลเดอร์พิเศษที่ขึ้นต้นด้วยขีดล่าง
6. ไปที่ **Settings → Pages** ใน repository
7. ใน **Build and deployment** เลือก **Source: Deploy from a branch**
8. เลือก **Branch: main** และโฟลเดอร์ **/(root)** แล้วกด **Save** หาก repository ใช้ชื่อ branch อื่น ให้เลือก branch ที่มี `index.html`
9. รอให้ GitHub เผยแพร่เสร็จ หน้า Pages จะแสดงลิงก์ **Visit site** ปกติเป็น `https://ชื่อบัญชี.github.io/twist-fork-menu/`
10. เปิดลิงก์จริง ทดลองเลือกเมนู จากนั้นแชร์ลิงก์นี้ให้เพื่อนได้เลย

ถ้าเห็นหน้า 404 ให้ตรวจว่า `index.html` อยู่ชั้นบนสุด, branch ใน Pages ถูกต้อง และงาน Pages ในแท็บ Actions เสร็จแล้ว ไฟล์และชื่อโฟลเดอร์ต้องเป็นตัวพิมพ์เล็กตรงตามต้นฉบับ

## สองทางเลือกการส่งรายการ

### 1. ส่งให้เพื่อน

- กดเพิ่มเมนู เปิด **มื้อนี้ของเรา → ส่งให้เพื่อน**
- ปรับจำนวนหรือลบรายการ ระบบรวมราคาจากจำนวนที่เลือก
- **แชร์ให้เพื่อน** เปิดเมนูแชร์ของอุปกรณ์ถ้ารองรับ หรือแสดงข้อความพร้อมลิงก์ให้คัดลอก
- เพื่อนเปิดลิงก์แล้วกด **ใช้รายการจากเพื่อน** เพื่อรับรายการและแก้ไขต่อ
- ลิงก์เก็บเฉพาะรหัสเมนูและจำนวน ไม่มีชื่อ เบอร์โทร หรือข้อมูลการจอง ไม่ใช่รายการที่ซิงก์ร่วมกันแบบสด ถ้าแก้ไขแล้วต้องแชร์ลิงก์ใหม่
- รายการที่เลือกบันทึกในเบราว์เซอร์เครื่องนั้น ล้างได้ด้วย **ล้างรายการทั้งหมด**

### 2. ส่งให้ร้านทาง LINE

- เปิด **มื้อนี้ของเรา → ส่งให้ร้าน**
- กรอกชื่อผู้สั่ง/ผู้จอง เบอร์ติดต่อ จำนวนคน วันที่ เวลาจอง และหมายเหตุ (ถ้ามี)
- กด **เตรียมส่ง LINE ร้าน** จะเห็นข้อความครบทั้งข้อมูลจอง เมนู จำนวน และยอดรวม
- ปุ่ม **คัดลอกข้อความ** อยู่ข้าง **เปิด LINE ร้าน** กดคัดลอก เปิด LINE วางข้อความ แล้วกดส่งด้วยตัวเอง
- ถ้า LINE ยังไม่มีแชตกับร้าน ให้เพิ่มเพื่อนร้านก่อน แล้ววางข้อความที่คัดลอกไว้ หากเปิดแอปไม่ได้ ให้เปิดลิงก์จากมือถือหรือใช้ LINE ID `@436zwulz`
- ถ้าคัดลอกอัตโนมัติไม่ได้ ให้แตะช่องข้อความ เลือกทั้งหมด แล้วคัดลอกเอง
- การเตรียมข้อความไม่ใช่การส่งออเดอร์หรือยืนยันการจอง ต้องรอร้านยืนยันโต๊ะ ราคา และรายการที่มีจำหน่าย
- ข้อมูลผู้จองอยู่ในหน่วยความจำระหว่างเปิดหน้าเว็บ ไม่เก็บใน GitHub, ฐานข้อมูล หรือ localStorage และไม่ส่งไปกับลิงก์เพื่อน เมื่อรีเฟรชหน้าข้อมูลจองจะหาย

## แก้ข้อมูลและอัปเดตเว็บภายหลัง

- **ราคา / ชื่อ / หมวดอาหาร:** แก้ใน `menu.js` ค่า `price` เป็นจำนวนบาท ห้ามเปลี่ยน `id` ของเมนูเดิมเพราะลิงก์ที่เคยแชร์ใช้รหัสนี้ ถ้าเพิ่มเมนูให้ใช้ `id` ใหม่ที่ไม่ซ้ำ
- **ข้อมูลร้าน / เวลาเปิดปิด / ข้อความหน้าเว็บ:** แก้ `index.html` หากเปลี่ยนเวลาเปิดหรือวันหยุด ให้แก้การตรวจจองในฟังก์ชัน `bookingErrors` ของ `app.js` ด้วย
- **LINE:** ลิงก์อยู่ใน `index.html` ทั้งส่วนข้อมูลร้านและหน้าข้อความส่งร้าน
- **สี / ขนาด / การจัดหน้า:** แก้ `style.css`
- **รูป:** อยู่ใน `assets/menu` และ `assets/dishes` ถ้าเปลี่ยนรูปให้รักษาชื่อไฟล์เดิม หรือแก้ชื่ออ้างอิงในโค้ดด้วย
- อัปโหลดไฟล์ที่แก้กลับ repository และกด Commit แล้ว GitHub Pages จะเผยแพร่ใหม่ตาม branch ที่ตั้งไว้ อาจต้องรีเฟรชหน้าเว็บเพื่อเห็นการแก้ไข
